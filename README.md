# SPT-Weapon-Build-Screen-Tilt
This SPT (Single Player Tark... Tushonka) mod unlocks the rotation on tiling your weapon in the build screen allowing for you to angle your weapon upside down or any angle along the left-right and up-down axis's.
# Requirements
SPT 4.1.6 (probably other versions too, feel free, have fun testing, and report results with what version)
# Installation
This mod goes in your SPT/BepinEx/Plugins folder
# Compatibility
I created this mod with [UIFixes](https://sp-mod.com/mod/1342/ui-fixes) by [Typon](https://sp-mod.com/user/46005/tyfon#mods) active but not required for my mod within my development install of SPT and had no issues but other than that there shouldn't be any compatibility issues as this is a fairly simple mod that is only targets WeaponPreview and the Rotate part of the file overriding the min and max tilt.

if there is any compatibility issues then please do report them to me and I will see what I can do.
